# needesign.com.br

Site estático da needesign, publicado no Netlify.

- Páginas: `index.html`, `orcamento/`, `portfolio/`, `blog/` (+ artigos), `servicos/`, `produtos/`, `consultoria/`, `marketing/`, `privacidade/`
- Configuração de segurança e cache: `netlify.toml`
- Redirecionamentos das URLs antigas do Wix: `_redirects`
- Leads do simulador: Netlify Forms (formulário `orcamento`)
